# 17 — 收缩旧导航并完成四角色路由集成

**What to build:** 移除生产与正式原型中的旧导航镜像和根路径业务回退，完成顾客、店员、店长、总部四角色规范路由的整体集成。

**Blocked by:** 06 — 顾客商品订单与报修路由; 08 — 店员商品订单队列与详情路由; 11 — 店长经营看板与现场运营路由; 15 — 总部门店配置、人员与审计路由; 16 — 正式原型剩余管理表面路由.

**Triage:** ready-for-agent

**State:** open

- [ ] 删除或收缩 `activePage`、稳定页签、`selectedId` 等旧导航镜像，使 pathname、search 和必要 path params 成为页面身份唯一事实来源。
- [ ] 生产应用与正式原型的菜单、页签、卡片、面包屑和返回入口均使用真实链接或等价导航语义，支持新标签页和复制地址。
- [ ] 根地址只执行规格定义的角色入口决策或规范重定向，不再渲染所有业务页面或充当业务地址别名。
- [ ] 建立可审查的完整规范路由清单，覆盖顾客、店员、店长和总部全部已承诺表面、详情参数及查询参数允许列表。
- [ ] 缺失、格式错误、未知查询参数、无权对象和无效门店代码按统一规则规范化或显示安全边界，不产生重定向循环。
- [ ] 旧根路径业务别名、旧页签入口和迁移 feature flag 不再可继续使用；不保留隐藏但可交互的陈旧页面副本。
- [ ] 跨角色集成 E2E 覆盖登录入口、角色边界、直接深链、刷新、后退/前进、复制地址、对象详情、脏表单和移动端返回。
- [ ] 生产与正式原型的构建、类型检查、lint 和路由相关测试全部通过，且控制台无新增路由、hydration 或重复 key 错误。
