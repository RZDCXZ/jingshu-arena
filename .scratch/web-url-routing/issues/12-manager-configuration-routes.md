# 12 — 店长门店配置路由

**What to build:** 把店长门店资料、机位、价格和商品配置拆成可直接访问的子路由，并保留表单保护和服务端门店边界。

**Blocked by:** 03 — 服务端角色上下文与深链守卫.

**Triage:** ready-for-agent

**State:** open

- [ ] `/manager/configuration` 规范重定向到 `/manager/configuration/profile`，不渲染依赖默认内存页签的中间页面。
- [ ] 门店资料、机位、价格和商品分别使用 `/manager/configuration/profile`、`/seats`、`/pricing` 和 `/products`，配置页签由当前 URL 完全受控。
- [ ] 机位和商品的 `q`、`area` 等适用筛选仅通过规格允许的查询参数表达；未知值被移除且后退、前进、刷新可恢复。
- [ ] 配置页签、侧栏和面包屑均使用真实链接；浏览器后退按访问顺序恢复先前子页和筛选。
- [ ] 未保存表单在站内链接、页签切换、浏览器后退和页面卸载前触发确认；取消离开时 URL 与草稿均不变化。
- [ ] 确认、编辑、预览等短暂对话框保持瞬时 UI 状态，不为其制造可分享地址或浏览器历史记录。
- [ ] 直接访问配置深链时由服务端会话确定当前门店，客户端参数不能切换到其他门店或扩大权限。
- [ ] `1440 × 1024` 和 `1024 × 768` E2E 覆盖四个配置子路由、筛选、脏表单保护、刷新、焦点和横向溢出。
