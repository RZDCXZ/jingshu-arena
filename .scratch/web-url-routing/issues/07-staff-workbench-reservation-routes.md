# 07 — 店员工作台、预约列表与详情路由

**What to build:** 让店员工作台、预约列表和预约详情拥有稳定、可恢复的 URL，并把列表筛选和右侧详情选择从组件内存迁移到规范路由。

**Blocked by:** 03 — 服务端角色上下文与深链守卫.

**Triage:** ready-for-agent

**State:** open

- [ ] 店员侧栏以真实链接在 `/staff/workbench` 和 `/staff/reservations` 间导航，浏览器标题、页面标题与当前侧栏一致。
- [ ] 预约状态、时间、异常、区域和机型筛选写入白名单查询参数；默认值省略，非法值清理后显示一次安全提示。
- [ ] 工作台数量下钻进入已应用相同筛选的预约列表 URL，而不是只修改内存预设。
- [ ] 选择预约进入 `/staff/reservations/:reservationId`，直接打开或刷新会读取同一服务端权威详情。
- [ ] 站内详情返回依赖浏览器历史恢复原筛选和列表滚动；直接详情的返回链接进入默认预约列表。
- [ ] 到店、开始使用、提前结束和取消继续使用按钮及现有服务端命令，命令结果不改变对象规范身份。
- [ ] URL 中的预约 ID 不扩大店员所属门店范围，跨店与不存在对象保持相同安全外观。
- [ ] `1440 × 1024` 和 `1024 × 768` E2E 覆盖侧栏、筛选、下钻、详情、刷新、后退/前进、焦点和横向溢出。
