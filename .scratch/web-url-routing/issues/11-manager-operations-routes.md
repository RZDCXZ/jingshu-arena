# 11 — 店长经营看板与现场运营路由

**What to build:** 将店长看板和现场运营接入稳定 URL，并在店员作业能力之上保持店长门店范围、筛选和共享壳一致。

**Blocked by:** 07 — 店员工作台、预约列表与详情路由; 09 — 店员报修队列与详情路由; 10 — 店员库存、班次与交接路由.

**Triage:** ready-for-agent

**State:** open

- [ ] 店长登录默认进入 `/manager/dashboard`，浏览器标题、页面标题和当前侧栏状态同步。
- [ ] 看板时间范围及适用筛选通过允许列表查询参数表达，并能通过后退、前进、复制地址和刷新恢复。
- [ ] 现场工作台与预约列表分别使用 `/manager/live-ops/workbench` 和 `/manager/live-ops/reservations`，现场预约详情使用 `/manager/live-ops/reservations/:reservationId`。
- [ ] 店长报修和库存入口复用既有受保护作业能力，同时生成 `/manager/...` 规范地址，不把店员地址作为店长的可继续使用别名。
- [ ] 直接打开任一店长运营地址时，服务端从会话解析门店范围；查询参数、对象 ID 或客户端状态不能扩大可见门店。
- [ ] 共享管理壳中的品牌、角色标识、侧栏、面包屑、返回入口和焦点恢复在看板与现场运营路由之间保持一致。
- [ ] 不存在、跨店或无权预约显示安全的错误边界；加载失败和重试停留在目标 URL 且不闪现上一对象。
- [ ] `1440 × 1024` 和 `1024 × 768` E2E 覆盖看板筛选、现场工作台、预约详情、刷新、后退、焦点和横向溢出。
