# 16 — 正式原型剩余管理表面路由

**What to build:** 在正式管理系统原型中完成店员、店长和总部路由迁移，让所有受影响表面可直接访问并支持浏览器历史。

**Blocked by:** 02 — 正式原型 History 路由 tracer.

**Triage:** ready-for-agent

**State:** open

- [ ] 正式原型中现有店员、店长和总部侧栏项、二级页签及对象详情全部映射到规格定义的规范路径，不再依赖 `activePage` 或等价导航状态。
- [ ] 已有顾客交接表面使用规格中的当前顾客规范地址；本票不扩展为完整顾客 H5 实现。
- [ ] 共享壳和各页面通过受控 `route`/参数 props 读取导航状态，页面内部不得维护第二份可与 URL 分叉的稳定选择。
- [ ] 菜单、页签、卡片和对象入口使用 History API 驱动的真实导航语义；浏览器后退、前进、直接打开和刷新恢复同一页面。
- [ ] 总部门店地址使用稳定 `storeCode`，示例数据、门店切换器和无效代码边界保持一致。
- [ ] 原型 QA 专用查询参数仅接受规格允许列表，不得与生产业务查询参数混用或掩盖规范化结果。
- [ ] 路由切换后标题、当前导航项、主内容焦点和滚动位置符合原型运行时契约，且不闪现上一页面数据。
- [ ] 正式原型构建、Sites 构建与既有交互测试通过，并新增 `1440 × 1024`、`1024 × 768` 的多角色路由 E2E。
