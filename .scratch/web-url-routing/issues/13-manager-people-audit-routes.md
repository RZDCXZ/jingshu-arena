# 13 — 店长人员、排班与审计路由

**What to build:** 为店长人员管理、排班考勤和审计建立规范路径，使管理任务可分享、可刷新并维持对象与门店授权。

**Blocked by:** 03 — 服务端角色上下文与深链守卫.

**Triage:** ready-for-agent

**State:** open

- [ ] `/manager/people` 规范重定向到 `/manager/people/employees`；员工、排班和考勤分别使用 `/manager/people/employees`、`/schedule` 和 `/attendance`。
- [ ] 人员页签和侧栏由当前 URL 受控，站内导航使用真实链接，后退、前进和刷新恢复正确页面及标题。
- [ ] 审计列表和事件详情分别使用 `/manager/audit` 与 `/manager/audit/events/:auditEventId`，从列表进入详情后后退恢复原筛选位置。
- [ ] 审计时间、操作者、动作和对象等适用筛选使用允许列表查询参数；未知值规范化且不会改变授权范围。
- [ ] 直接打开员工、排班、考勤或审计深链时，服务端从会话解析当前门店；跨店、不存在和无权对象显示相同安全边界。
- [ ] 排班或人员编辑的脏表单在页签切换、站内导航、浏览器后退和页面卸载前触发离开确认。
- [ ] 加载、空态、错误与重试留在目标 URL，且快速切换事件详情不会闪现上一事件内容。
- [ ] `1440 × 1024` 和 `1024 × 768` E2E 覆盖人员三页、审计筛选与详情、刷新、后退、焦点和横向溢出。
