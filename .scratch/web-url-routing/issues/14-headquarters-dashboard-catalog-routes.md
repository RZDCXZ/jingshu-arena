# 14 — 总部看板、门店比较与连锁目录路由

**What to build:** 为总部经营看板、门店比较和连锁目录建立稳定 URL，使跨门店分析和目录页签可以可靠分享与恢复。

**Blocked by:** 03 — 服务端角色上下文与深链守卫.

**Triage:** ready-for-agent

**State:** open

- [ ] 总部登录默认进入 `/hq/dashboard`，经营看板和门店比较分别使用 `/hq/dashboard` 与 `/hq/comparison`。
- [ ] 门店比较的 `range`、`from`、`to`、`metric` 和 `store` 通过允许列表查询参数表达，冲突值规范化且后退、前进、刷新可恢复。
- [ ] 连锁商品与机型目录分别使用 `/hq/catalogs/products` 和 `/hq/catalogs/machines`，目录页签由 URL 完全受控。
- [ ] 看板、比较和目录间的侧栏、页签、面包屑及返回入口使用真实链接，并同步当前项、浏览器标题和页面标题。
- [ ] 只读指标或目录行的快速查看继续使用对话框或抽屉，不为瞬时展开态创建深链或历史记录。
- [ ] 直接访问任一总部深链时由服务端验证总部角色和可见门店集合；查询参数中的门店代码不能扩大数据范围。
- [ ] 加载、空态、错误与重试留在目标 URL，快速切换指标或目录不会显示上一选择的陈旧内容。
- [ ] `1440 × 1024` 和 `1024 × 768` E2E 覆盖看板、比较筛选、两类目录、刷新、后退、焦点和横向溢出。
