# 08 — 预约模拟支付、取消、过期与详情

**What to build:** 让顾客完成明确不扣款的预约确认，随后看到可信的倒计时、到店窗口、取消、过期、模拟退款和历史事件。

**Blocked by:** 07 — 预约待确认、冲突约束与价格/体验券快照。

**Triage:** ready-for-agent

**State:** resolved

- [x] 预约模拟支付入口、确认、处理中、成功和失败状态都明确写明“不扣款”，不请求任何真实支付凭据。
- [x] 模拟支付把待确认预约变为已确认并把占用体验券标记已使用，金额严格使用创建时快照。
- [x] 待确认超过十分钟自动过期并释放座位和体验券；已确认开始十五分钟后未到店自动按爽约过期。
- [x] 顾客可在预约开始前取消待确认或已确认预约；未模拟支付不产生模拟退款，已确认使用前取消产生全额模拟退款并恢复体验券。
- [x] 相关读取和时间推进会惰性处理到期记录，重复处理不会产生第二份退款、事件或副作用。
- [x] WEB-C02 预约详情展示七种状态、倒计时、到店窗口、座位与机型、价格快照、体验券、退款、关联对象和不可变时间线。
- [x] 终态详情不显示非法主动作，只提供查看历史或再次预约；失败与超时保留可恢复入口和原幂等键。
- [x] 状态、业务事件、副作用和审计事件在同一事务提交，非法跳转保持当前状态并写过滤后的审计。
- [x] 使用 Product Design 插件的 image-to-code 工作流实现 MP-08/MP-09 对应的 Web H5 页面，模拟支付、取消确认、倒计时、时间线和终态导航均可操作。
- [x] 使用 Product Design design-qa 在 360px 的待确认、已确认、已取消、已过期和退款状态下对照原型，P0/P1/P2 清零并通过。
- [x] 固定时钟测试穷举十分钟保留、到店窗口、十五分钟爽约、取消边界、券恢复、退款和幂等行为。
