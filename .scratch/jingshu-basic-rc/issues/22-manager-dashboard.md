# 22 — 单店经营看板与经营日下钻

**What to build:** 让店长从本店真实业务记录理解收入、座位使用、维护损失、订单、报修、库存、考勤和交接情况，并能下钻到构成事实。

**Blocked by:** 12 — 店员商品订单履约、取消与损耗; 16 — 备件领退、解决说明与维修验证闭环; 18 — 交接班快照、接班确认与异常; 20 — 店长未来价格计划与门店商品配置; 21 — 店长员工、排班与考勤更正。

**Triage:** ready-for-agent

**State:** resolved

- [x] WEB-M01 默认展示当前经营日和最近七个经营日，并支持最近十四个种子经营日内的自定义范围；全部日期按上海时间 06:00 边界计算。
- [x] 模拟营业额只统计已完成预约和已完成商品订单的最终模拟金额，扣除模拟退款且不包含未完成、取消或过期交易。
- [x] 预约最终未退款的半小时价格片段归入片段所在经营日；商品订单整体归入完成时经营日。
- [x] 运营座位利用率与维护不可用率并列展示并使用各自定义分母，不合并成单一上座率。
- [x] 订单完成率排除未支付过期与处理中订单，未完成订单和订单损耗作为独立积压/损耗指标。
- [x] 报修展示未关闭数量、优先级、中位处理时长和维护分钟；考勤分开显示准时、迟到、缺勤，交接只显示异常数量。
- [x] 所有图表和指标由当前沙箱记录计算，禁止硬编码数字、综合评分、最佳门店排名或利润暗示。
- [x] 指标卡提供定义、文本摘要和下钻；下钻后的列表保持相同门店、经营日和筛选语境。
- [x] 使用 Product Design 插件的 image-to-code 工作流实现经营日范围、指标卡、图表、定义说明、异常摘要和下钻交互，图表加载、空数据与错误状态可操作。
- [x] 使用 Product Design design-qa 在 1440×1024 与 1024×768 下对照管理端原型，检查双座位指标、图表尺寸、中文标签、最近经营证据时间线和全部审计入口，P0/P1/P2 清零并通过。
- [x] 公式测试以固定记录验证跨 06:00、价格片段退款、订单分母、中位数、维护分母和十四日范围。
