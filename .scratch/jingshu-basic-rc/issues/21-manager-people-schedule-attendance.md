# 21 — 店长员工、排班与考勤更正

**What to build:** 让店长维护所属门店的背景员工和未来排班，并以追加证据的方式修正迟到、缺勤或签退事实。

**Blocked by:** 17 — 店员班次、模拟考勤与手动签退; 18 — 交接班快照、接班确认与异常。

**Triage:** ready-for-agent

**State:** resolved

- [x] WEB-M07 展示本店员工工作名、员工编号、店员/店长角色、任职状态和固定所属门店。
- [x] 店长可以创建、编辑和停用背景员工，但四位公开角色使用的受保护演示人物不可停用、删除或替换。
- [x] 员工存在当前/未来班次或未完成报修分派时，停用必须显示依赖并阻止提交。
- [x] WEB-M08 使用半小时网格或等价时间轴创建和编辑 4–12 小时班次，支持跨午夜且拒绝同一员工重叠。
- [x] 未来未签到班次可编辑或取消，已签到班次时间不可直接修改。
- [x] 人员覆盖不足生成可保存的告警和预览，不被误呈现为阻断错误。
- [x] WEB-M09 同时显示原始考勤事实和追加更正；更正迟到、缺勤或签退时间必须提供最多 200 字原因，不能覆盖原记录。
- [x] 店长仅管理所属门店；总部只能只读汇总，其他门店数据与一线动作均被拒绝并审计。
- [x] 使用 Product Design 插件的 image-to-code 工作流实现背景员工、未来班次、覆盖预览、考勤更正、缺勤详情和交接快照等专用弹窗，所有当前入口与业务字段一致。
