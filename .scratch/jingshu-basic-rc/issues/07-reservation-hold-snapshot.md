# 07 — 预约待确认、冲突约束与价格/体验券快照

**What to build:** 让顾客选定一个座位后获得十分钟排他预约保留，并在提交前清楚看到不可变的价格和体验券结果。

**Blocked by:** 05 — 双时钟、时间推进与轮换重置; 06 — 顾客三店浏览、座位可订性与价格预览。

**Triage:** ready-for-agent

**State:** resolved

- [x] 顾客可创建一条仅含一位顾客、一个明确座位和一段连续时间的待确认预约。
- [x] 创建事务同时检查座位时段冲突、同一顾客跨店有效预约重叠、营业时间、预约期限和当前座位运营状态。
- [x] Postgres 时间范围排斥约束最终阻止座位及顾客时段重叠；应用预检查只用于提供可行动提示。
- [x] 待确认预约排他占用座位时段十分钟，并在同一事务内占用至多一张符合门店、业务、时段、最低金额和有效期的预约体验券。
- [x] 创建时保存门店、座位、区域、机型、每个半小时片段、优惠与总额价格快照；后续配置变化不修改它。
- [x] 任一步冲突或写入失败时，预约、座位占用、体验券占用、事件和审计均不留下部分结果。
- [x] 关键创建命令支持幂等重试；相同键同负载返回首次预约，不同负载返回稳定冲突。
- [x] WEB-C01 的预约确认状态展示门店、座位、完整日期时间、价格片段、总额、体验券适用解释和“不扣款”说明。
- [x] 使用 Product Design 插件的 image-to-code 工作流实现 MP-07 对应的 Web H5 界面；价格明细展开、体验券选择、不可用原因、冲突失效和返回选座均有真实交互。
- [x] 使用 Product Design design-qa 在 360px 的无券、可用券、不可用券、金额为零和冲突失效状态下比较设计原型，P0/P1/P2 清零并通过。
- [x] 真实 Postgres 并发测试证明二十个同座同时段请求只能成功一个，同一顾客跨店重叠也只能保留一个合法结果。
