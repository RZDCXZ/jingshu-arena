# 26 — 总部三店比较、全沙箱审计与导出

**What to build:** 让总部运营并列比较三家门店的经营与异常事实，并在授权范围内查看全沙箱审计和导出数据。

**Blocked by:** 22 — 单店经营看板与经营日下钻; 23 — 本店审计与筛选 CSV 导出; 25 — 总部固定三店配置与人员排班汇总。

**Triage:** ready-for-agent

**State:** claimed

- [ ] WEB-H01 并列展示三店模拟营业额、运营座位利用率、维护不可用率、订单完成率、库存告警、报修、考勤和交接异常。
- [ ] WEB-H02 支持按指标、门店和经营日范围比较趋势，并复用单店相同公式和 06:00 经营日边界。
- [ ] 三店保持中性并列，不生成综合分、最佳门店、冠军色、利润或伪造 SLA。
- [ ] 指标和异常可以下钻到授权只读列表/详情；总部下钻始终隐藏一线命令。
- [ ] WEB-H07 允许按当前沙箱全部三店范围筛选审计，并导出预约、订单、库存流水、报修、排班和审计 CSV。
- [ ] 总部导出继续使用当前筛选、排序、UTF-8 BOM、金额和经营日定义；导出动作写审计。
- [ ] 图表提供文本摘要和可访问数据表或明细，不以颜色作为门店、异常或趋势的唯一编码。
- [ ] 使用 Product Design 插件的 image-to-code 工作流实现连锁总览、门店比较、异常下钻、全沙箱审计和导出范围/完成态，筛选和入口均有真实行为。
- [ ] 使用 Product Design design-qa 在 1440×1024 与 1024×768 下对照管理端原型，复核三店标记、图表尺寸、密度、琥珀/红色异常语义、只读动作和导出状态，P0/P1/P2 清零并通过。
- [ ] 测试证明总部公式与单店结果一致、不能执行一线动作，并只访问当前沙箱三店。
