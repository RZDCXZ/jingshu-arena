# 39 — 截图索引、演示视频、字幕与证据包

**What to build:** 让审阅者无需运行全部测试，也能通过可追溯证据快速确认竞枢的业务深度、视觉质量和发布可信度。

**Blocked by:** 36 — 全系统安全、并发、可访问性与性能门禁; 37 — 基础设施探针与生产等价预览。

**Triage:** ready-for-agent

**State:** open

- [ ] 建立版本化证据索引，覆盖 Web 四角色、小程序本地模式、核心状态机、权限拒绝、事务回滚、看板、导出和故障降级。
- [ ] 测试、性能、可访问性、基础设施和兼容性报告同时保留人类可读 Markdown 与机器可读结果摘要。
- [ ] 截图索引记录页面/状态、角色、门店、业务时间、视口、构建版本和对应设计 QA，不用无上下文图片替代证据。
- [ ] 原始测试产物、截图和报告保留校验信息；大体积浏览器追踪、视频和二进制作为 Release 资产，不写入 Git 历史。
- [ ] 制作 4–6 分钟、1080p 的完整业务演示视频，覆盖公开入口、顾客预约、店员到店/订单/维修、店长验证/看板、总部比较/导出、重置和小程序本地故事。
- [ ] 视频持续或在关键节点明确说明虚构数据、模拟支付不扣款、小程序不与 Web 同步和没有真实门店服务。
- [ ] 提供准确同步的中文字幕与英文字幕文件，关键领域术语和业务状态与中英文文档一致。
- [ ] 视频不展示 Secret、真实账号、个人通知、真实身份、内部管理凭据或未授权第三方资产。
- [ ] 使用通过 Product Design QA 的生产构建录制；录制前复核关键页面没有因录屏视口产生裁切、浮层遮挡或字体回退。
- [ ] 证据包标明仍待最终域名、网络、真机或审核确认的项目，不伪造或提前填写通过结果。
