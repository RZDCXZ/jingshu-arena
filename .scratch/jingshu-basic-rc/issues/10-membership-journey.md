# 10 — 会员成长、体验券与统一行程

**What to build:** 让顾客清楚看到跨三店共享的会员成长、体验券状态以及预约、订单、报修和模拟退款组成的完整个人行程。

**Blocked by:** 08 — 预约模拟支付、取消、过期与详情；09 — 店员办理到店、使用与完成预约。

**Status:** ready-for-agent

- [ ] 每位顾客只有一份经营方级会员档案，等级为青铜、白银、黄金，门槛固定为 0、500、1500，累计成长值终身不降级。
- [ ] 主演示顾客初始为白银、860 成长值，并拥有一张预约体验券和一张商品体验券。
- [ ] 已完成预约按体验券减免后的最终模拟金额每满一元获得一点成长值；取消、过期和设备退款片段不重复发放。
- [ ] 体验券展示可用、占用、已使用、已过期及关联交易和释放条件，不提供储值、转让、折现或手工调整。
- [ ] WEB-C03 行程按当前、未来和历史聚合预约，并在关联数据存在时展示商品订单、报修和模拟退款。
- [ ] 会员和行程查询只返回当前顾客数据，跨顾客、跨沙箱对象枚举被安全拒绝。
- [ ] 使用 Product Design 插件的 image-to-code 工作流，以 MP-16/MP-17 的信息架构实现 Web H5 行程与会员页面；Tab、券状态、成长记录、空状态和关联对象跳转均可操作。
- [ ] 使用 Product Design design-qa 在 360px 的白银会员、四种体验券状态、当前行程和空历史状态下对照小程序原型并适配 Web 沙箱标识，P0/P1/P2 清零并通过。
- [ ] 领域测试覆盖等级边界、成长值取整、终身不降级、券状态与预约完成/取消/过期结果。
- [ ] 页面持续说明这是演示数据，不使用“积分”“余额”“返现”或真实账户措辞。
