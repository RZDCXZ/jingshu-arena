# 31 — 小程序预约完整流程

**What to build:** 让小程序体验者在本地沙箱完成选门店、时段、机型、座位、体验券和不扣款模拟支付，并可继续体验到店与使用中的顾客状态。

**Blocked by:** 08 — 预约模拟支付、取消、过期与详情；30 — 小程序本地沙箱与预约优先外壳。

**Status:** ready-for-agent

- [ ] MP-05 支持未来七天日期、00–23 时、00/30 分、1–8 小时时长、区域和机型选择，今天已过去的半小时片段不可选。
- [ ] MP-06 针对所选时段显示可订、已预留、使用中、维护中和已选五种可辨识状态，支持 96 座门店的分区浏览。
- [ ] MP-07 展示座位、完整时间、半小时价格片段、总价、预约体验券及不可用原因。
- [ ] MP-08 在入口、确认、处理中和结果持续说明模拟支付不扣款，并防止重复点击产生重复预约。
- [ ] MP-09 覆盖待确认、已确认、已到店、使用中、已完成、已取消和已过期，展示倒计时、到店窗口、金额、退款及事件时间线。
- [ ] 本地存储适配器执行与 Web 相同的预约冲突、顾客跨店重叠、价格快照、体验券占用、过期和取消规则。
- [ ] MP-02 的顾客引导从本地业务记录推导，不使用手工勾选。
- [ ] 提供明确标注的角色外“推进本地演示”工具，使已确认预约产生预置合法的已到店/使用中结果；它不得显示为顾客权限或员工后台。
- [ ] 每次业务命令成功后原子持久化当前状态、业务事件和本地引导进度，重启后保持一致。
- [ ] 使用 Product Design 插件的 image-to-code 工作流，以小程序原型 MP-02/05–09 的相同页面和状态实现原生交互；时间选择、时长单值、机型单选、选座固定栏、支付和取消均可操作。
- [ ] 使用 Product Design design-qa 在 iPhone 与 Android 视口对照预约条件、座位图、确认、支付和七种详情状态，验证固定主动作、安全区、触控目标和动态金额，P0/P1/P2 清零并通过。
- [ ] 共享领域与本地适配器测试覆盖普通/立即预约、半小时价格、冲突、十分钟保留、券、取消、过期和重启恢复。
