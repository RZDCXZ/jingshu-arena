# 32 — 小程序会员与行程历史

**What to build:** 让小程序体验者从本机业务记录查看会员成长、体验券，以及预约、订单、报修和模拟退款组成的统一行程。

**Blocked by:** 10 — 会员成长、体验券与统一行程；31 — 小程序预约完整流程。

**Status:** ready-for-agent

- [ ] MP-16 按当前、未来和历史分组展示本地预约，并在存在时聚合关联商品订单、报修和模拟退款。
- [ ] 当前没有业务记录时提供开始预约的可执行空状态；关联卡可以进入对应详情并正确返回行程位置。
- [ ] MP-17 展示青铜、白银、黄金等级、当前成长值、下一等级门槛和终身不降级说明。
- [ ] 体验券按可用、占用、已使用和已过期分组，展示关联交易和释放条件。
- [ ] 成长记录从本地已完成预约和后续已完成商品订单计算，取消、过期和退款片段不产生错误成长值。
- [ ] 页面只使用“成长值”“体验券”“模拟退款”等正式术语，不出现积分、余额、返现或云账户暗示。
- [ ] 本地数据重启后保持，主动重置后会员、券、行程和引导一起恢复标准种子。
- [ ] 使用 Product Design 插件的 image-to-code 工作流，以 MP-16/17 的当前、未来、历史、券四态和成长记录实现原生页面，Tab 与关联对象导航具有真实行为。
- [ ] 使用 Product Design design-qa 在 393×852 iPhone 和 427×952 Android 下比较会员、行程、空状态和长内容，验证字体放大、触控目标、底部导航和滚动安全区，P0/P1/P2 清零并通过。
- [ ] 本地契约测试覆盖等级边界、成长值、券状态、历史聚合、重启恢复和重置。
