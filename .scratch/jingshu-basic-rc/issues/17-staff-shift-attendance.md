# 17 — 店员班次、模拟考勤与手动签退

**What to build:** 让店员查看自己的计划班次，按沙箱业务时间执行明确标注的模拟签到和手动签退，并看到迟到或缺勤结果。

**Blocked by:** 04 — 服务端角色上下文与共享演示壳; 05 — 双时钟、时间推进与轮换重置。

**Triage:** ready-for-agent

**State:** resolved

- [x] 每名员工固定属于一家门店并具有店员或店长角色，不支持跨店任职或借调。
- [x] 班次开始和结束按半小时对齐，时长 4–12 小时，可跨午夜但同一员工不得重叠。
- [x] WEB-S09 展示本人当前、未来班次、签到窗口、原始考勤事实和下一合法动作。
- [x] 员工可从班次开始前 30 分钟模拟签到；开始后签到标记迟到，班次结束仍未签到由业务时钟标记缺勤。
- [x] 签到后只能由员工手动签退，系统不得自动伪造签退时间。
- [x] 尚未签到的未来班次允许后续管理操作；已签到班次时间不可直接修改。
- [x] 模拟签到持续说明不使用定位、人脸、门禁或真实考勤连接器。
- [x] 当前员工只能操作自己的考勤；其他门店、其他员工和总部一线动作被拒绝并审计。
- [x] 使用 Product Design 插件的 image-to-code 工作流实现本人班次、签到、迟到、缺勤和签退交互，处理中、重复提交和非法时间窗口有明确反馈。
- [x] 使用 Product Design design-qa 在 1440×1024 与 1024×768 下对照管理端原型的班次与工作台摘要，验证时间层级、主动作、状态文本和键盘操作，P0/P1/P2 清零并通过。
- [x] 固定业务时钟测试覆盖提前签到边界、迟到、缺勤、跨午夜、重复签到、手动签退和时钟推进。
