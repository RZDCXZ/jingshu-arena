# 27 — 实时失效通知、轮询与只读降级

**What to build:** 让同一沙箱的多个角色及时看到彼此变化，并在实时连接或后端故障时诚实降级而不伪造写入成功。

**Blocked by:** 04 — 服务端角色上下文与共享演示壳; 05 — 双时钟、时间推进与轮换重置; 08 — 预约模拟支付、取消、过期与详情。

**Triage:** ready-for-agent

**State:** open

- [ ] 服务端以约 25 秒短连接发送沙箱级 SSE 失效通知，通知只说明资源已变化，客户端随后从 API 重新获取权威状态。
- [ ] SSE 正常结束后自动重连；被缓冲、提前终止或不可用时退化为短轮询，再失败时提供手动刷新。
- [ ] WEB-G02 清楚显示实时、轮询、手动、陈旧和重新连接状态，不把任何模式包装成更强能力。
- [ ] 角色切换、时间推进、业务命令和重置会通知同沙箱标签；旧角色或旧沙箱标签阻止继续写入并提供刷新/表单处理路径。
- [ ] 数据库或 API 不可用时 WEB-G07 使用随构建发布的标准种子快照进入只读模式，所有写按钮禁用且不切换到浏览器可写 Mock。
- [ ] 写入超时不显示乐观成功，而是使用原幂等键查询或重试，并以服务端最终结果校准界面。
- [ ] WEB-G08 覆盖安全请求关联 ID、429 重试时间、超时、幂等冲突、服务不可用和非法状态恢复动作。
- [ ] SSE、轮询和错误日志只记录白名单安全字段，不泄露会话、请求体或内部响应。
- [ ] 使用 Product Design 插件的 image-to-code 工作流实现实时状态、手动刷新、只读横幅、禁用动作、陈旧提示、旧标签阻断和错误恢复，所有可见控制均可执行。
- [ ] 使用 Product Design design-qa 在管理端 1440×1024、1024×768 及 360px 顾客 H5 的实时/轮询/只读状态下对照原型，P0/P1/P2 清零并通过。
- [ ] 浏览器 E2E 覆盖 SSE 重连、轮询降级、手动刷新、多标签角色变化、写入超时和只读模式不产生业务副作用。
