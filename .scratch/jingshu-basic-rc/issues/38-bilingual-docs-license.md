# 38 — 中英双语文档、许可证与发布说明

**What to build:** 让作品集审阅者能够用中文或英文独立理解、运行、测试和评估竞枢，并清楚区分真实实现、演示边界和已知限制。

**Blocked by:** 36 — 全系统安全、并发、可访问性与性能门禁; 37 — 基础设施探针与生产等价预览。

**Triage:** ready-for-agent

**State:** open

- [ ] 提供相互链接的中文主说明和完整英文说明，架构、运行方式、边界、测试、演示入口和已知限制保持一致。
- [ ] 正式采用 MIT License，并完成依赖、字体、图标、图片、生成资产和其他素材的许可证与归属检查。
- [ ] 文档说明单一虚构经营方、固定三店、四个 Web 角色、小程序本地沙箱、模拟支付、不收集真实身份和不连接真实设备。
- [ ] 架构说明覆盖 pnpm workspace、Web/Hono/小程序、领域与存储适配器、Postgres/RLS、双时钟、种子、事件/审计、Blob 和实时降级。
- [ ] 领域文档与 ADR 索引使用既定术语，任何实现中新增或改变的决策均有记录，未静默覆盖 ADR-0001 至 ADR-0024。
- [ ] 本地开发、环境变量、临时 Postgres、迁移、seed/reset、测试、构建、生产等价预览和部署步骤可由干净环境复现。
- [ ] 安全说明覆盖匿名演示、权限模型、图片净化、限流、数据寿命、清理和日志白名单。
- [ ] 测试说明链接领域、契约、集成、E2E、性能、可访问性、小程序和基础设施报告，并解释每个门禁的通过状态。
- [ ] 发布说明列出功能、迁移、已知限制、回滚方式、Web 入口、小程序源码/状态以及自定义域名和审核状态。
- [ ] 不提交 Secret、真实个人数据、真实门店地址、不可再分发资产或大体积追踪/视频二进制。
- [ ] 中英文术语、命令、版本和链接由自动或人工检查确认一致，所有引用页面可访问。
