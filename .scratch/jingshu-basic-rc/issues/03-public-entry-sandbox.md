# 03 — 公开入口与版本化三店沙箱

**What to build:** 让首次访客先理解竞枢的用途与演示边界，选择角色后才得到一个与其他访客隔离、可重试创建的三店演示世界。

**Blocked by:** 01 — 可复现工作区与门禁骨架；02 — 统一跨端设计基线与合成命名。

**Status:** ready-for-agent

- [ ] WEB-G00 在创建任何沙箱前展示产品用途、虚构数据、不发生真实支付、不接入真实设备、无需注册以及四个公开角色，默认建议从顾客开始。
- [ ] 页面打开、爬虫访问或只读了解不会创建沙箱；只有访客明确选择角色后才发起创建。
- [ ] 沙箱以单一幂等事务生成经营方、固定三店、受保护演示人物、schema 版本和种子版本；部分失败不会暴露半成数据。
- [ ] 相同创建键和相同负载重试返回同一个成功结果，不产生重复沙箱或重复种子。
- [ ] 不同访客获得不可互读写的沙箱；公开 URL 不包含 sandbox_id、会话凭证或可写能力。
- [ ] WEB-G01 展示创建中、成功、超时、失败和安全重试状态，不伪造成功或进入只有部分数据的页面。
- [ ] 全部可见数据使用已确认的棱镜旗舰店、星桥标准店、极点新店和栖光市，并持续标注“演示数据”。
- [ ] 使用 Product Design 插件的 image-to-code 工作流，以管理端公开入口与初始化原型的对应状态实现 WEB-G00/G01；角色卡、边界说明、主行动、加载与错误交互均可操作。
- [ ] 使用 Product Design design-qa 在 1440×1024 和 360px 公开入口状态下对照设计原型，P0/P1/P2 全部清零且最终结果为 passed。
- [ ] API 与真实 Postgres 集成测试覆盖隔离、事务回滚、幂等重试、版本记录和未选择角色不创建沙箱。
