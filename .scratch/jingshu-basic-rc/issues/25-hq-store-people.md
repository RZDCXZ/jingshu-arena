# 25 — 总部固定三店配置与人员排班汇总

**What to build:** 让总部运营在不变成超级管理员的前提下配置固定三店，并只读理解各店人员和排班覆盖。

**Blocked by:** 21 — 店长员工、排班与考勤更正；24 — 总部商品资料与机型档案。

**Status:** ready-for-agent

- [ ] WEB-H05 只允许在棱镜旗舰店、星桥标准店和极点新店之间切换并配置，不能新增、删除或停用门店。
- [ ] 总部可配置三店展示资料、营业时间、区域、座位、机型、未来价格和商品范围，遵守与店长相同的历史引用、版本和依赖规则。
- [ ] 每种配置使用与业务一致的专用字段、作用范围、未来影响和提交动作，列表编辑按钮可打开当前记录。
- [ ] 总部不能从配置页执行到店、订单履约、维修处理、入库、盘点、签到或交接。
- [ ] WEB-H06 汇总三店员工人数、角色、覆盖与未来班次，只读展示且明确提示需切换对应店长处理排班。
- [ ] 人员汇总不暴露真实身份数据，只使用虚构工作名和业务所需字段。
- [ ] 所有配置写入审计并遵守幂等、跨沙箱隔离和历史兼容；只读人员请求不得产生审计噪声。
- [ ] 使用 Product Design 插件的 image-to-code 工作流实现门店选择、展示资料、区域座位、价格、商品范围和人员排班汇总，未授权入口仅显示安全只读说明。
- [ ] 使用 Product Design design-qa 在 1440×1024 与 1024×768 下对照管理端原型，复核三店颜色标记、未来配置弹窗、人员表间距、只读提示和专用确认内容，P0/P1/P2 清零并通过。
- [ ] 权限测试证明总部具有列明配置能力但无法调用任何一线命令，店长仍不能越过所属门店。
