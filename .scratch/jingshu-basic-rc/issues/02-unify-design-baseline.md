# 02 — 统一跨端设计基线与合成命名

**What to build:** 让管理系统、顾客 H5 和原生小程序引用同一套品牌、虚构门店、城市与主演示数据，使后续生产页面只有一套无歧义的视觉和内容真相。

**Blocked by:** None — can start immediately.

**Triage:** ready-for-agent

**State:** resolved

- [x] 跨端正式名称统一为“棱镜旗舰店”“星桥标准店”“极点新店”，虚构城市统一为“栖光市”。
- [x] 三店仍分别对应 96/64/40 座和既定营业时间、经营特征；名称统一不得改变规格中的业务事实。
- [x] 管理端与小程序的设计契约、可运行原型、合成数据和可见文案不再出现“折线标准店”“启点新店”或“澄江市”等旧命名。
- [x] 人物、商品、备件、金额和事件继续使用虚构合成内容，不引入真实地址、品牌或个人资料。
- [x] 使用 Product Design 插件检查两套原型中受命名变化影响的页面、弹窗、筛选、图表和时间线，避免截断、换行或信息密度回归。
- [x] 管理端原型的导航、角色切换、业务弹窗和主演示仍可完整操作；小程序 MP-00 至 MP-19 及四条主流程仍可完整操作。
- [x] 对受影响状态执行 Product Design design-qa，同视口比较更新后的原型与各自已选视觉源，修复全部 P0/P1/P2。
- [x] 两套最新 QA 记录的最终结果均为 `passed`（通过），覆盖记录同步说明统一后的正式名称。
