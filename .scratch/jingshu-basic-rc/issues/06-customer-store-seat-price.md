# 06 — 顾客三店浏览、座位可订性与价格预览

**What to build:** 让顾客浏览三家虚构门店，并按日期、时段、区域和机型找到一个明确可订座位及可解释的半小时价格。

**Blocked by:** 03 — 公开入口与版本化三店沙箱；04 — 服务端角色上下文与共享演示壳。

**Status:** ready-for-agent

- [ ] WEB-C00/C01 展示棱镜旗舰店、星桥标准店和极点新店的营业时间、座位规模、区域、机型档案和演示边界。
- [ ] 顾客可以选择未来七天内、半小时对齐、1–8 小时且不跨门店非营业时间的日期与时段；立即预约预览使用当前半小时片段起点。
- [ ] 座位只保存正常或维护中的运营状态；可订、已预留和使用中结果按当前查询时段与预约记录推导。
- [ ] 96 座旗舰店支持分区浏览、筛选、缩放或等价局部导航，点击目标可用且不会一次性压缩成不可操作的小点。
- [ ] 机型档案固定体现标准型、竞技型、旗舰型及既定座位数量和体验描述，不绑定真实硬件品牌。
- [ ] 价格预览按工作日/周末、跨午夜和半小时片段使用整数分计算，展示每个片段依据和总价，不出现浮点误差。
- [ ] 改变时段、区域或机型会重新查询可订性；已选座位失效时清除选择并解释原因。
- [ ] 使用 Product Design 插件的 image-to-code 工作流，以小程序 MP-01、MP-03 至 MP-06 的信息架构和管理端 Web 沙箱视觉语言实现顾客 H5，筛选、时间选择、座位选择、图例和返回修改均可操作。
- [ ] 使用 Product Design design-qa 在 360px 顾客 H5 和旗舰店座位图关键状态下对照对应设计原型，验证字体、触控目标、图例、固定操作区和安全区，P0/P1/P2 清零并通过。
- [ ] 领域和 API 测试覆盖经营日、营业时间、普通/立即预约边界、可订性推导、周末系数、跨午夜及价格片段。
- [ ] 中端移动设备上旗舰店座位图首次可交互不超过一秒，筛选、缩放和选择反馈不超过 100 毫秒。
