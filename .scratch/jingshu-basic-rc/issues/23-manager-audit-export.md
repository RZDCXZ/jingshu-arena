# 23 — 本店审计与筛选 CSV 导出

**What to build:** 让店长追踪本店关键变化和拒绝结果，并把当前所见筛选数据准确导出为可由 Excel 打开的 CSV。

**Blocked by:** 18 — 交接班快照、接班确认与异常; 20 — 店长未来价格计划与门店商品配置; 21 — 店长员工、排班与考勤更正; 22 — 单店经营看板与经营日下钻。

**Triage:** ready-for-agent

**State:** open

- [ ] 业务状态、配置、库存、考勤更正、角色切换、导出和重置均写审计；越权与非法跳转写拒绝审计，普通读取不制造噪声。
- [ ] 审计只追加，记录业务时间、服务器记录时间、人物、角色、沙箱、门店、动作、对象、原因、请求关联 ID 和白名单前后差异。
- [ ] Cookie、令牌、Secret、图片内容、完整请求体、SQL 和不必要自由文本不得进入审计、日志或错误响应。
- [ ] WEB-M10 支持按时间、人物、角色、门店、动作、对象类型和结果筛选，并可查看安全的详情差异。
- [ ] 店长只能读取和导出所属门店审计，跨店对象枚举返回安全拒绝且不泄露对象存在性。
- [ ] 预约、订单、库存流水、报修、排班和审计分别按当前筛选与排序导出，不生成原生 XLSX。
- [ ] CSV 使用 UTF-8 BOM，金额、完整日期时间、06:00 经营日、列定义、排序和行数与页面一致。
- [ ] 导出确认展示数据类型、门店范围、经营日范围和预计行数；失败不声称已下载并保留筛选以便重试。
- [ ] 使用 Product Design 插件的 image-to-code 工作流实现审计筛选、详情、前后差异、导出范围、处理中、完成和失败状态。
- [ ] 使用 Product Design design-qa 在 1440×1024 与 1024×768 下对照管理端原型，复核高密度表格、双时间、详情抽屉、导出结果和键盘路径，P0/P1/P2 清零并通过。
- [ ] 集成测试验证角色范围、白名单过滤、拒绝事件、CSV BOM/列/排序/金额/经营日及相同筛选重试。
