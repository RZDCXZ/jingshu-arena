# 20 — 店长未来价格计划与门店商品配置

**What to build:** 让店长通过未来生效版本调整本店座位价格，并独立配置本店商品的上架、售价和库存告警阈值。

**Blocked by:** 11 — 顾客商品下单、整单库存预留与模拟支付；19 — 店长门店资料、区域与座位配置。

**Status:** ready-for-agent

- [ ] WEB-M05 展示价格计划的门店、区域、机型、星期、时段、生效区间和版本状态。
- [ ] 新价格只能创建未来生效版本；相同适用范围的生效区间不得重叠，历史版本不被覆盖。
- [ ] 提交前展示匹配范围、工作日/周末半小时金额、生效时间、重叠结果和“不会影响已有价格快照”说明。
- [ ] 价格使用整数分计算并兼容跨午夜与 06:00 经营日，已存在预约继续使用原快照。
- [ ] WEB-M06 允许本店配置总部商品的上架状态、门店售价和独立低库存阈值，但不能修改总部商品资料。
- [ ] 下架或改价不改变历史订单快照；被业务引用的门店商品配置只能归档/停用。
- [ ] 店长只能配置所属门店，总部范围和其他门店数据不可由前端参数冒充。
- [ ] 所有配置命令幂等并在服务端确认后更新页面，超时使用原幂等键查询或重试。
- [ ] 使用 Product Design 插件的 image-to-code 工作流实现价格版本、重叠检查、门店商品专用表单、编辑和归档交互；可见入口不得打开无关通用字段。
- [ ] 使用 Product Design design-qa 在 1440×1024 和 1024×768 下对照管理端原型，复核价格范围、表格密度、商品配置字段、保存按钮和成功反馈，P0/P1/P2 清零并通过。
- [ ] 领域与数据库测试覆盖版本选择、重叠拒绝、快照不变、跨午夜定价、商品下架历史和跨店权限。
