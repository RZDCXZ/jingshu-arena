# 20 — 店长未来价格计划与门店商品配置

**What to build:** 让店长通过未来生效版本调整本店座位价格，并独立配置本店商品的上架、售价和库存告警阈值。

**Blocked by:** 11 — 顾客商品下单、整单库存预留与模拟支付; 19 — 店长门店资料、区域与座位配置。

**Triage:** ready-for-agent

**State:** resolved

- [x] WEB-M05 展示价格计划的门店、区域、机型、星期、时段、生效区间和版本状态。
- [x] 新价格只能创建未来生效版本；相同适用范围的生效区间不得重叠，历史版本不被覆盖。
- [x] 提交前展示匹配范围、工作日/周末半小时金额、生效时间、重叠结果和“不会影响已有价格快照”说明。
- [x] 价格使用整数分计算并兼容跨午夜与 06:00 经营日，已存在预约继续使用原快照。
- [x] WEB-M06 允许本店配置总部商品的上架状态、门店售价和独立低库存阈值，但不能修改总部商品资料。
