# 09 — 店员办理到店、使用与完成预约

**What to build:** 让棱镜旗舰店店员从现场工作台找到顾客预约，并按合法时间窗口完成到店、开始使用、提前结束或取消。

**Blocked by:** 04 — 服务端角色上下文与共享演示壳; 08 — 预约模拟支付、取消、过期与详情。

**Triage:** ready-for-agent

**State:** resolved

- [x] WEB-S01 工作台按当前优先事项展示到店窗口内、已到店待开始、使用中及异常预约，并能下钻到相同筛选的列表或详情。
- [x] WEB-S02 默认使用当前 06:00 经营日，支持状态、时间、区域、机型和异常筛选，并展示计划时间、座位、顾客工作名和到店窗口。
- [x] WEB-S03 展示状态、唯一主要动作、计划时间、价格快照、关联订单/报修/退款和不可变事件，不提供任意状态下拉框。
- [x] 店员只能在开始前 30 分钟至开始后 15 分钟办理到店，只能在计划开始后把已到店预约推进为使用中。
- [x] 店员可以提前结束使用中预约并记录原因；到计划结束仍在使用中的预约由业务时钟自动完成。
- [x] 店员或店长只能在使用前带原因取消；原因长度、纯文本和隐私提示符合契约。
- [x] 所有命令支持幂等重试并原子保存当前状态、预约事件、副作用和审计；非法状态和跨店请求被拒绝并审计。
- [x] 顾客 H5 在角色切回后看到同一沙箱中的到店、使用、完成或取消结果，无需乐观伪造。
- [x] 使用 Product Design 插件的 image-to-code 工作流实现 WEB-S01/S02/S03，对应的队列、筛选、详情面板、办理到店、开始使用、提前结束和取消交互均可执行。
- [x] 使用 Product Design design-qa 在 1440×1024 工作台和 1024×768 管理适配下对照管理端原型，重点复核当前任务、右侧检查器、终态无冗余按钮、焦点和导航收起状态，P0/P1/P2 清零并通过。
- [x] 状态机测试穷举允许/拒绝路径，并以真实 API/数据库验证门店范围和时间窗口。
