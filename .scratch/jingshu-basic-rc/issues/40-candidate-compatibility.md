# 40 — 自定义域名、浏览器、大陆三网与真机候选验收

**What to build:** 在项目所有者提供最终域名和必要访问条件后，对候选构建执行真实网络、浏览器和设备验收，形成正式 RC 的外部证据。

**Blocked by:** 36 — 全系统安全、并发、可访问性与性能门禁；37 — 基础设施探针与生产等价预览。

**Status:** ready-for-agent

- [ ] 最终自定义域名由项目所有者通过安全方式提供并配置，正式候选使用该域名和有效 HTTPS，不以 EdgeOne 默认项目域名代替。
- [ ] 在真实 Chrome、Edge、Safari 和微信内置浏览器完成公开入口、顾客 H5、角色切换、主演示关键动作和只读/错误恢复 smoke。
- [ ] 大陆访问覆盖电信、联通、移动、早晚时段、普通浏览器和微信内置浏览器，并保留构建版本、日期、地点、设备、网络、样本数和原始结果。
- [ ] 样本不足、网络失败或平台限制如实记录，不根据有限结果承诺长期跨境网络 SLA。
- [ ] 小程序在微信开发者工具和至少一台真机走完预约、订单、报修与重置；权限拒绝、键盘、安全区和本地重启恢复得到验证。
- [ ] 有合适小程序账号、类目和明确授权时真实尝试一次提审并记录结果；缺少凭据或审核失败不伪造结果且不阻塞基础 RC。
- [ ] 候选环境执行迁移、健康检查、Secret/漏洞扫描、沙箱创建、Blob 净化、SSE/轮询、清理和回滚演练。
- [ ] 使用 Product Design 插件对最终域名的关键 Web 页面和真机小程序截图执行发布前 design-qa，同状态比较已选视觉源/原型；P0/P1/P2 清零且最终结果为 passed。
- [ ] 管理端至少覆盖 1440×1024、1280px 和 1024×768；公开入口与顾客 H5 至少覆盖 360px；小程序覆盖既定 iPhone 与 Android 视口。
- [ ] 兼容性报告汇总通过、失败、限制、复测和原始证据，并明确是否满足合并 main 的候选门禁。
