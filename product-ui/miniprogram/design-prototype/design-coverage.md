## 设计结论

- 产品第一任务是预约明确座位；首页只保留一个预约主行动。
- “柜台商品”仅在预约已到店或使用中时出现；“座位报修”仅在预约使用中时出现。
- 深海军蓝为底色，青色表达流程和可用性，荧光青柠只用于主行动、当前导航和关键金额。
- 所有人物、门店、金额、订单、图片和事件均为合成演示数据；不要求登录、真实身份或真实支付。
- 正式地点统一为栖光市、棱镜旗舰店、星桥标准店与极点新店；三店继续对应 96/64/40 座及既定营业时间和经营特征。
- 状态由本机沙箱持久化，可在 MP-18 二次确认后恢复标准种子。
- 预约时间支持未来 7 天、00–23 时与 00/30 分组合选择，时长可在 1–8 小时内单值调整；今天已经过去的半小时片段不可选。

## 可完整操作的四条故事

1. 预约：`首页 → 选时段 → 选座位 → 预约确认 → 模拟支付 → 预约详情`。
2. 到店后商品：`预约详情 → 推进到已到店/使用中 → 商品目录 → 购物车 → 订单确认 → 订单详情`。
3. 使用中报修：`预约详情 → 座位报修 → 图片权限回退/样例图 → 提交 → 公开处理动态 → 退款影响`。
4. 本地恢复：`会员 → 本地演示设置 → 二次确认重置 → 标准预约首页`。

## 组件与可用性

- 四个一级导航：主页、门店、行程、会员。
- 一级导航切换根页面；重复点击当前 Tab 保持当前页面，不重复入栈或触发转场。
- 预约、订单和报修详情统一采用“当前状态 + 关键事实 + 上下文行动 + 事件时间线”。
- 固定主行动与 iPhone/Android 安全区、模拟键盘联动；有效触控目标按移动端尺寸设计。
- 状态同时使用文字、图标和色彩；表单有语义标签，图片有替代文本。
- 图标统一使用 Phosphor；品牌使用仓库位图；报修照片为无品牌虚构设备图片，没有 CSS/内联 SVG 资产替代。
