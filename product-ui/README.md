# 产品 UI

这里集中存放竞枢面向用户的界面产品说明、设计交付和长期维护的可运行设计参考：

- `miniprogram/`：顾客侧原生微信小程序。
- `management-system/`：Web 公开演示入口、店员操作台、店长后台与总部运营视图。

基础 RC 规格和实施议题仍保留在 `.scratch/jingshu-basic-rc/`；跨界面共享的领域词汇与业务规则位于根目录 `CONTEXT.md` 和 `docs/adr/`。

## 共享内容基线

所有顾客、店员、店长和总部界面使用同一组正式合成地点名称：

- 虚构城市：栖光市。
- 三家门店：棱镜旗舰店、星桥标准店、极点新店。

这里是跨界面名称的单一真相源。各端产品合同、原型、种子数据、截图和 QA 证据引用这些名称；名称变化先更新这里，再在同一任务中同步所有受影响表面。
