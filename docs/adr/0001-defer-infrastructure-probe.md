# 将竞枢基础设施探针延后至部署阶段

独立执行文档原本要求在业务编码前验证 EdgeOne、香港 Hono、Neon、Blob、自定义域名和中国大陆访问方案。当前决定先实现完整基础 RC 的业务与本地验证，再在部署阶段补做探针，以优先推进产品闭环；在探针通过前，运行时版本、云端适配和部署拓扑均视为暂定，并接受探针失败可能导致的技术设计调整或返工。正式 RC 仍须通过相关部署与访问验收；若届时 EdgeOne Cloud Functions 仍只提供已经结束上游支持且无法确认安全维护的 Node 20，必须迁移 API 运行时，或由项目所有者明确记录并接受该风险，不能把构建环境支持 Node 24 当作函数运行时已经通过验证。
