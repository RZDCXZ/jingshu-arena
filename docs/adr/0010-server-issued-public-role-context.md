# 公开角色由服务端签发权限上下文

公开演示允许任何访客选择顾客、店员、店长或总部运营预设角色，但每次选择都由服务端映射到固定演示人物并签发包含沙箱、角色和门店范围的安全会话。角色上下文属于整个浏览器会话而非单个标签页；任一标签切换角色时轮换角色上下文与 CSRF，其他标签中的旧角色写操作立即失效并需要刷新。API 只从 HttpOnly 服务端会话取得授权上下文，不信任客户端传入的角色名、门店或沙箱标识。该方案不假装存在真实员工身份认证，重点证明对象级授权和隔离；代价是无法在同一浏览器会话的多个标签中同时维持不同角色，主演示采用明确的顺序切换。
