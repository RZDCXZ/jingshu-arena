# 冻结目录历史事实并把商品适用范围与门店运营配置分离

商品和机型档案保存可变的当前资料；订单、预约和报修在创建时保存各自需要的商品、价格与机型快照，后续目录改名或归档不得追溯重写这些历史事实。报修因此直接保存机型代码、名称和体验描述快照，并由数据库在旧写入路径遗漏快照时兼容补齐；机型外键继续保留引用完整性，已引用档案只能归档而不能硬删除。

总部商品适用门店范围独立保存，不复用门店商品的上架、售价、阈值或库存字段。范围扩大会为新门店建立默认未上架、零售价、零库存的门店配置；范围缩小会保留既有门店商品与库存记录，但门店配置写入、顾客目录和新订单必须同时命中当前适用范围。已有订单仍按不可变快照继续履约。

该结构增加一张范围关联表、一列报修快照和读取时的范围联接，换取总部目录权限不会暗中变成门店运营写入、历史事实不受当前名称影响，并允许旧沙箱通过前向回填兼容升级。
