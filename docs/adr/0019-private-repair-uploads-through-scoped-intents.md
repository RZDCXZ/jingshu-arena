# 报修图片通过范围化上传意图进入私有 Blob

API 为经过授权的报修单签发绑定沙箱、对象、文件类型和大小的一次性短期上传意图，客户端先把文件直接传入私有隔离区；完成接口再读取并实际解码文件，核验类型、尺寸与像素数，重新编码以移除 EXIF 等元数据，只有净化成品才会以随机对象名关联报修单，原隔离文件删除且成品只通过短期签名地址读取。若目标平台缺少直传能力，上传适配器可以每次代理一张不超过 5 MB 的原始文件，但仍必须经过相同净化；若部署探针证明无法在函数限制内安全解码和重新编码，生产演示关闭任意上传并使用内置样例图，而不降低为保存原文件。该选择增加了隔离区、净化和清理流程，却避免匿名访客把定位元数据、伪造图片或主动内容直接带入可访问资产。
