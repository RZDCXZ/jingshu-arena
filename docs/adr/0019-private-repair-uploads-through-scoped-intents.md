# 报修图片通过范围化上传意图进入私有 Blob

API 为经过授权的报修单签发绑定沙箱、对象、文件类型和大小的一次性短期上传意图，客户端先把文件直接传入私有隔离区；意图在写入前以原子状态转换认领，重放请求不能覆盖已暂存对象。完成接口再读取并实际解码文件，核验类型、尺寸与像素数，在有界并发预算内重新编码以移除 EXIF 等元数据，只有净化成品才会以随机对象名关联报修单，原隔离文件删除且成品只通过按当前权限重新签发的短期地址读取。

生产适配器必须使用部署提供的共享持久私有卷；临时目录只用于开发。净化前先登记持久清理任务，成品关联成功时与业务事务一起删除该任务；进程中断、隔离文件删除失败或沙箱轮换时由可重试清理工作器收尾，未知提交结果不得直接删除可能已经关联的成品。若目标平台缺少直传能力，上传适配器可以每次代理一张不超过 5 MB 的原始文件，但仍必须经过相同净化；若部署探针证明无法在函数限制内安全解码和重新编码，生产演示关闭任意上传并使用内置样例图，而不降低为保存原文件。该选择增加了隔离区、净化和持久清理队列，却避免匿名访客把定位元数据、伪造图片或主动内容直接带入可访问资产。
